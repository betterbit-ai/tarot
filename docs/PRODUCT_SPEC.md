# Product Specification

## Product contract

리더 등장 -> 질문 -> 카드 준비 -> 78장 셔플 -> 펼침 -> 직접 3장 선택 -> 순차 공개 -> 읽는 호흡 -> 제휴 제안 -> 결과 -> 연결된 스토리 -> 공유 -> 새 질문.

이 순서와 각 장면의 감정적 역할은 기능 수보다 우선한다.

## Experience principles

- 한 화면에는 하나의 주 행동만 둔다.
- 입력은 선택 사항이다.
- 결과를 보기 위해 제휴 링크를 누르게 하지 않는다.
- 결과는 세 장의 뜻을 나열하지 않고 배경, 현재 긴장, 앞으로의 방향으로 연결한다.
- 확정적 예언, 의료/법률/투자 판단, AI 문구를 피한다.

## Success measures

- 375, 390, 430, 768, 1440px에서 전체 흐름을 막힘 없이 완료한다.
- 카드 선택이 즉시 반응하고 세 장 제한이 명확하다.
- 결과와 공유 링크에 질문이 노출되지 않는다.
- full dataset 유무와 관계없이 정상 리딩이 나온다.
- 제휴를 끄거나 URL을 빼도 결과가 열린다.

상세 acceptance criteria는 `spec/spec.md`에 있다.
