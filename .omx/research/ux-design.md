# UX / Visual Direction Research

작업 전제:
이 레포는 현재 코드가 비어 있어서 실제 프레임워크를 확인할 수 없다. 이 문서는 구현 스택에 덜 종속적이되, 모바일 웹 1차 경험을 기준으로 바로 옮겨 심을 수 있게 작성한 연구안이다. 제품의 핵심은 “타로를 보는 행위” 자체의 밀도이며, 화면은 그 행위를 방해하지 않고 조용히 지지해야 한다.

## Design Read

이 프로젝트는 한국어 모바일 우선의 리추얼형 소비자 서비스로 읽는다. 톤은 `midnight / candlelight / old paper / brass` 쪽으로 기울고, 디자인 언어는 `boutique tarot shop + independent publication + quiet mystery`가 가장 적합하다. 핵심 차별점은 “AI가 해석한 화면”이 아니라 “진짜 리더가 테이블 위에서 카드를 읽어주는 느낌”이다.

## Product Posture

- 사용자는 앱을 “분석 도구”가 아니라 “짧게 몰입하는 타로 의식”으로 받아들여야 한다.
- 한 화면에는 한 번에 하나의 주된 행동만 보여준다.
- 모든 상태는 질문을 받는 과정, 섞는 과정, 고르는 과정, 읽는 과정으로 자연스럽게 이어져야 한다.
- 과장된 신비주의, 챗봇 연출, 반짝이 이펙트 남발은 금지한다.

## State-by-State Mobile Ritual

| State | 사용자의 감정 | 화면 구성 | 상호작용 | 모션 / 타이밍 | 마이크로카피 |
|---|---|---|---|---|---|
| 1. 입장 / 리더 등장 | “무언가 진짜 시작된다” | 어두운 테이블, 리더의 실루엣 또는 손, 짧은 인사 | 자동 진입, 버튼은 1개만 | 240ms 페이드 인 + 120ms 안정화 | “왔네요.” / “오늘은 무엇이 궁금한가요?” |
| 2. 질문 떠올리기 | 질문을 정리하는 집중 | 질문 입력창 1개, 예시 질문 2~3개, 건너뛰기 가능 | 입력 또는 바로 진행 | 120ms 포커스 리액션 | “질문이 없어도 괜찮아요.” |
| 3. 카드 준비 | 기대감 상승 | 리더의 손이 덱을 가져오고 테이블 중앙에 놓임 | CTA는 하나만 활성화 | 180ms 준비 동작 | “카드를 준비할게요.” |
| 4. 셔플 | 긴장감 | 78장 덱이 한 덩어리에서 움직이기 시작 | 수동 개입 없음 | 1.8~2.4s 셔플 시퀀스 | 문장 없이 사운드/시각만으로 전달 |
| 5. 펼침 / 스프레드 | 카드의 양감이 생김 | 카드가 테이블 위로 부채꼴 또는 아크 형태로 펼쳐짐 | 스크롤 / 드래그 / 탭 선택 가능 | 500~700ms fan-out | “세 장을 골라주세요.” |
| 6. 첫 번째 선택 | 첫 감각의 확정 | 선택 카드만 떠오르고 나머지는 얕게 눕음 | 탭 1회 | 90~120ms lift + 140ms settle | “1 / 3” |
| 7. 두 번째 선택 | 패턴이 보이기 시작 | 선택 상태가 누적되고 선택 가능 영역이 명확해짐 | 탭 1회 | 동일한 lift 규칙 | “2 / 3” |
| 8. 세 번째 선택 / 확정 | 완성감 | 카드 3장이 고정되고 CTA가 살아남 | 확정 버튼 활성화 | 160ms 강조 상태 전환 | “이 카드로 볼게요” |
| 9. 공개 / 리빌 | 기대와 몰입 | 카드가 중앙으로 모이고 한 장씩 뒤집힘 | 자동 진행 | 카드당 560~700ms, 700ms 간격 | 카드명만 우선 노출 |
| 10. 리딩 호흡 | 해석이 시작됨 | 카드와 짧은 문장, 시선이 잠시 머무는 여백 | 조작 없음 | 1.2~1.8s 정지감 | “세 장을 같이 볼게요.” |
| 11. 제휴 인터스티셜 | 흐름이 끊기지 않는 광고 | 결과를 가리지 않는 얇은 모달 / 시트 | 스킵 가능, 클릭 가능 | 220ms 진입 / 180ms 종료 | “잠깐, 결과를 보는 동안” |
| 12. 결과 / 스토리 | 이해와 안도 | 3장 연결 스토리, 핵심 문단, 실용적인 한 줄 | 공유 / 다시 보기 | 300~400ms 종이 내려앉는 느낌 | “세 장이 이렇게 이어집니다.” |
| 13. 공유 / 재시도 | 마무리와 재방문 | 공유 카드, 링크 복사, 새 질문 시작 | 명확한 2개 CTA만 | 180ms 전환 | “다른 질문으로 다시 보기” |

## Visual System

### Tone

- 밤, 종이, 잉크, 금속, 먼지 같은 재질감
- 조용하지만 싸구려가 아닌 신비감
- “예쁜 점집”보다 “정제된 독립 출판물”에 가까운 인상

### Palette

- Background: midnight charcoal
- Surface: deep ink / smoke
- Paper: warm ivory
- Linework: soft graphite
- Accent: muted brass only

권장 색 방향:

- 배경: `#101114`, `#17161a`
- 종이/본문면: `#f1eadf`
- 보조 면: `#d8cfbf`
- 선 / 테두리: `#4a443d`
- 강조색: `#b79a5d`

규칙:

- 강조색은 한 가지로 잠근다.
- 보조 효과는 그라데이션보다 음영과 질감으로 만든다.
- 반짝이, 보랏빛 광원, 유리 같은 범용 AI 미학은 쓰지 않는다.

### Type

- 본문은 높은 가독성의 한국어 산세리프를 쓴다.
- 헤드라인은 서적 같은 인상을 주는 세리프 또는 세리프 계열 타이틀 서체를 고려한다.
- 단, 장식이 본문을 이기면 안 된다.
- 문장은 짧고, 여백이 많고, 설명은 한 번에 한 덩어리씩 읽히게 한다.

### Shape / Material

- 카드, 패널, 모달은 같은 라운드 규칙을 공유한다.
- 그림자에는 순수 검정 대신 배경색에 섞인 따뜻한 그림자를 쓴다.
- 표면은 과하게 둥글지 않게, 종이 모서리 같은 절제된 라운드를 유지한다.
- 질감은 2~4% 정도의 은은한 grain으로만 넣는다.

## Motion Timings

| 장면 | 권장 시간 | 역할 |
|---|---:|---|
| 리더 등장 | 220~280ms | “사람이 들어왔다”는 감각 |
| 질문 진입 | 120ms | 입력이 가볍게 반응 |
| 카드 준비 | 160~220ms | 손이 덱을 가져오는 동작 |
| 셔플 | 1800~2400ms | 몰입의 중심, 너무 빠르면 가짜 같음 |
| 스프레드 | 500~700ms | 덱이 테이블에 살아난다 |
| 카드 선택 | 90~120ms | 손맛, 과한 반짝이 금지 |
| 카드 공개 | 560~700ms / 장 | 실제 카드가 뒤집히는 느낌 |
| 장면 사이 간격 | 650~900ms | 다음 카드에 시선이 머물 시간 |
| 리딩 호흡 | 1200~1800ms | 결과가 “나온다”가 아니라 “읽힌다” |
| 제휴 시트 | 220ms in / 180ms out | 흐름을 끊지 않는 얇은 개입 |
| 결과 전환 | 300~400ms | 종이 한 장이 내려앉는 느낌 |

모션 원칙:

- 셔플은 반복 루프가 아니라 하나의 사건처럼 보이게 한다.
- 카드 선택은 과장된 particle 대신 lift, shadow, edge highlight만 사용한다.
- reduced motion에서는 셔플과 리빌을 단순한 페이드/슬라이드로 바꾼다.

## 78-Card Spread Interaction

### Primary Interaction

- 모바일에서는 78장을 전부 일렬로 보여주지 말고, 테이블 위에 겹친 부채꼴 / 아크 구조로 표현한다.
- 기본은 카드 뒷면 중심이다. 앞면 이미지는 선택된 카드만 노출한다.
- 카드가 많다는 사실은 “양감”과 “밀도”로 느끼게 하고, 사용자는 3장을 고르는 행위에만 집중하게 한다.

### Selection Rules

- 탭이 기본, 드래그는 보조다.
- 첫 번째, 두 번째, 세 번째 선택은 시각적으로 같은 규칙을 따른다.
- 선택된 카드는 6~8px 정도 떠오르고, 테두리와 그림자가 아주 약하게 살아난다.
- 세 장이 다 선택되면 나머지 카드는 배경처럼 눕는다.

### Performance Rules

- 78개의 고해상도 앞면을 한 번에 렌더링하지 않는다.
- 보이는 카드 뒷면은 반복 가능한 단일 자산으로 처리한다.
- 앞면은 선택된 카드 3장만 실제로 보여준다.
- 작은 화면에서는 팬 구조보다 horizontal rail이 더 안정적일 수 있다. 이 경우에도 겹침과 깊이는 유지한다.

## Tasteful Reader Concept

가장 세련된 리더는 “완전히 설명되지 않은 존재”다.

- 얼굴 전면 노출보다 손, 테이블, 실루엣, 램프 빛이 더 좋다.
- 과한 캐릭터화, 점성술사 코스튬, 크리스털 볼, 챗봇 말풍선은 피한다.
- 리더는 사용자를 점검하는 사람이 아니라, 조용히 카드에 집중하는 안내자여야 한다.
- 대사는 짧고 낮게 유지한다. 길게 말하지 않는다.

권장 톤 예시:

- “카드를 펼칠게요.”
- “세 장을 같이 볼게요.”
- “이 흐름으로 읽어보겠습니다.”

금지 톤 예시:

- “우주가 당신에게 말합니다!”
- “AI가 분석한 완벽한 답변입니다.”
- “지금 바로 운명을 확인하세요!”

## Affiliate Interstitial Treatment

이 인터스티셜은 광고가 아니라 “잠깐의 제안”처럼 보여야 한다.

- 결과 열람을 막지 않는다.
- 반드시 건너뛰기가 가능해야 한다.
- 제휴임을 숨기지 않는다.
- 추천은 1개가 가장 좋다. 복수 상품 캐러셀은 흐름을 망친다.
- 시트나 얇은 모달이 적합하고, 전체 화면 광고처럼 보이면 안 된다.

권장 구성:

- 짧은 안내문
- 추천 상품 1개
- `쿠팡에서 보기`
- `건너뛰고 결과 보기`

운영 규칙:

- 제휴 URL이 없더라도 전체 플로우는 정상 작동해야 한다.
- 링크 클릭이 결과 열람의 조건이 되면 안 된다.
- 제휴임을 명시하는 레이블은 작게, 그러나 명확하게 둔다.

## Result / Share Composition

결과 화면은 세 장의 의미를 “붙이는” 것이 아니라 “연결하는” 화면이어야 한다.

### Result Screen Structure

- 상단: 세 장이 만들어낸 전체 흐름 한 줄
- 중단: 카드 3장 각각의 해석
- 하단: 세 카드를 엮은 현실적인 문장
- 보조: 오늘의 조언 또는 다음 행동 한 줄
- 액션: 공유 / 다시 보기

### Share Composition

- 공유 카드에는 질문을 기본적으로 넣지 않는다.
- 공유 URL에는 카드 조합과 결과 요약만 담는다.
- 카드 이름, 순서, 핵심 문장만으로도 결과가 이해돼야 한다.
- 링크 복사는 짧고 단정하게, 이미지 공유는 종이 카드처럼 보이게 한다.

공유물에 들어가면 좋은 요소:

- 서비스명
- 세 장의 카드명
- 한 줄 스토리
- 날짜 또는 세션 표시

공유물에 넣지 말아야 할 요소:

- 질문 원문 전체
- 제휴 정보
- 내부 모델/AI 문구

## Accessibility / Reduced Motion

- 모든 상호작용은 44px 이상 터치 영역을 확보한다.
- 카드 선택 상태는 색만으로 구분하지 말고 위치, 그림자, 테두리로 함께 보여준다.
- 스크린리더용으로 “1 / 3 선택됨”, “카드 공개됨” 같은 상태 변화를 명확히 읽어야 한다.
- 대비는 AA 이상을 기본으로 한다.
- reduced motion에서는 셔플, 플립, 패럴랙스, 스케일 펄스를 크게 줄이거나 제거한다.
- 자동 재생 사운드와 과한 진동은 쓰지 않는다.
- 포커스 순서는 질문 → 덱 → 확인 → 결과 → 공유의 흐름을 따른다.

## Responsive QA Checklist

- 320px 폭에서 질문 입력, 카드 선택, CTA가 모두 한 화면 안에서 읽히는가
- 375px / 390px / 414px 폭에서 3장 선택 상태가 답답하지 않은가
- iPhone SE급 작은 화면에서 카드 부채꼴이 과밀해지지 않는가
- 세로 / 가로 회전 시 결과 화면이 깨지지 않는가
- iOS Safari 주소창 변화에 흔들리지 않는가
- 안전 영역(safe area) 하단 버튼이 홈 인디케이터와 겹치지 않는가
- 제휴 시트가 결과 텍스트를 가리지 않는가
- 공유 카드가 모바일 화면 안에서 잘리지 않는가
- reduced motion 켠 상태에서도 플로우가 자연스러운가
- 느린 네트워크나 자산 지연 상황에서도 카드 뒷면과 주요 문구는 즉시 보이는가

## Anti-AI-Slop Guardrails

- 보라색 AI 그라데이션 금지
- 챗봇 말풍선 금지
- “분석 중”, “AI가 해석했습니다” 같은 문구 금지
- 유리 같은 반사, 스파클, 과한 빛 번짐 금지
- 카드 UI를 전부 동일한 라운드 카드로 복제하는 패턴 금지
- 점성술/신비주의 클리셰를 과장한 복장과 소품 금지
- 결과를 늦춘다는 이유로 로딩 스피너를 반복 노출하는 것 금지
- “운명을 확인하세요” 같은 마케팅 문구보다 짧고 단정한 한국어를 쓴다
- 모든 섹션을 반짝이는 카드 묶음으로 만들지 않는다
- 미학은 신비롭지만 촌스럽지 않아야 한다. 과장보다 절제가 우선이다

## Final Direction

이 서비스는 AI 데모처럼 보여서는 안 된다. 사용자는 “잘 만든 작은 타로점”을 발견했다고 느껴야 한다. 따라서 전체 경험은 어둡고 조용한 테이블 위에서, 리더의 손과 카드와 짧은 문장만으로 완성되어야 한다. 화려한 연산보다 중요한 것은 리듬, 재질감, 그리고 세 장이 한 문장처럼 읽히는 감각이다.
